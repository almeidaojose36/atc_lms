# Imagens instrucionais ATC

Seis capturas próprias de exemplos fictícios de formação, nas aplicações para a Web em português de Portugal. Os ficheiros usados pelo LMS e pelas páginas imprimíveis estão em `cursos/{word,excel,powerpoint}/manual/figures/amostra-*.jpg`.

O catálogo apresenta «Ver exemplos» para os três cursos. Cada tarefa contém um título, uma captura real, três passos e uma verificação do resultado. Os conteúdos são definidos em `manual/exemplos-atc.json`; a versão autónoma para impressão está em `manual/exemplos-atc.html`.

`manifesto.json` identifica as seis imagens e os respetivos hashes. As capturas mantêm a interface real; a marca ATC e as instruções ficam na página do manual. Os ficheiros HTML devem permanecer junto da pasta `figures/`.

Consultar `../../handoff.md` para reproduzir e atualizar a integração.
