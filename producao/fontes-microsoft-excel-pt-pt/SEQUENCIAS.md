# Sequências curtas para os apresentadores

Vocabulário português europeu; vozes personalizadas com sotaque angolano. Cada cena, incluindo todos os planos, terá no máximo 8 segundos. Medir a locução gerada antes da montagem. Os quatro SVG são exemplos animados; o quinto visual é um clip real, já exportado. Não há nova locução nesta entrega.

| Cena | Visual existente | Guião sugerido |
|---|---|---|
| 1 — Estrutura | animar-estrutura.svg | Um livro contém folhas. Cada célula é identificada pela coluna e pela linha. |
| 2 — Criar | animar-criar-livro.svg | Crie um livro em branco e guarde-o com um nome fácil de reconhecer. |
| 3 — Dados | animar-introduzir-dados.svg | Selecione uma célula, escreva o valor e prima Enter para confirmar. |
| 4 — Série | animar-preencher-serie.svg | Escreva Jan e Fev. Selecione ambos e arraste a alça para continuar. |
| 5 — Soma | atc-calcular-soma-8s.mp4 | Nesta demonstração, a função SOMA calcula o total dos materiais de formação. |

Para uma nova montagem de cada SVG: 0–1 s, apresentar o objetivo; 1–6 s, executar a demonstração; 6–8 s, manter o resultado para leitura. Não comprimir várias cenas num único clip de 8 segundos.
