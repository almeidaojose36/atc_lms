## Visuais para o LMS

Quatro esquemas SVG animados estão no manual: estrutura do livro, criar livro, introduzir dados e continuar uma série. São esquemas pedagógicos ATC, não capturas oficiais. O clip de interação real de 8 segundos com `=SOMA(D2:D4)` e respetivo VTT estão em `../../cursos/excel/visuais/animados/`. É silencioso e preparado para receber uma explicação curta dos apresentadores.

Abrir `index.html` para comparar as fontes e visualizar os materiais. O curso continua com o estado «em breve»; este lote prepara os materiais sem anunciar um curso completo.
