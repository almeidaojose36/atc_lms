ATC · ANGBU TRAINING CENTRE

Aprender com exemplos · Microsoft Word

Duas tarefas guiadas com capturas reais das aplicações para a Web. Os comandos podem variar na aplicação instalada.

ATC · EXEMPLO 01

Organizar um relatório profissional

O separador Base reúne os comandos de formatação e os estilos do documento.

  1. Escreva o título e os dados da sessão.
  2. Aplique um estilo de título à primeira linha e aos subtítulos.
  3. Organize as atividades numa lista curta.

Verifique: Verifique se o relatório tem um título, secções e atividades fáceis de localizar.

ATC · EXEMPLO 02

Encontrar os elementos para inserir

O separador Inserir permite acrescentar tabelas, imagens e números de página.

  1. Abra o separador Inserir.
  2. Localize os comandos Tabela e Imagem.
  3. Escolha o comando adequado ao elemento que pretende adicionar.

Verifique: A captura mostra os comandos disponíveis; nenhum elemento novo foi inserido neste exemplo.
